# 本地资产依赖

公共仓库只保存项目自研代码、配置、地图数据、生成管线和允许再分发的项目产物。Fab、Marketplace 及其他第三方商店内容必须由开发者在自己的账户下取得并安装，不能随仓库再次分发。

## 使用原则

- 不从其他开发者机器、缓存目录或打包产物复制商店源文件。
- 不把商店资源转存到 Git LFS、Release 附件或 Art 源目录规避忽略规则。
- 项目发布包可以包含依据许可证烘焙后的游戏内容；公共源码仓库不提供可独立提取和复用的原始资产包。
- 替换或移除依赖后，同步更新本文件和地图引用审计。
