# 文档入口

当前事实只从以下文件开始读：

- `00_项目现状.md`：项目做到哪、哪些已验证、哪些只是代码存在。
- `01_落地路线图.md`：从现在到作品集成品的实际顺序和验收闸门。
- `02_开发规约.md`：所有后续开发的工作边界、事实来源和完成标准。
- `03_本地资产依赖.md`：公共仓库不再分发的第三方本地资产目录。
- `design/`：仍有效的设计总纲与规格。
- `audits/`：技术审计、旧地图预览和纠错资料。
- `research/`：方案调研，不等于已采用决策。

有冲突时，优先级为：最新明确决策 → `00_项目现状.md` / `01_落地路线图.md` → 当前设计文档。
