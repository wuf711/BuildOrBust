> 验收标准（用户 2026-08-10 定）：
> 1. 符合游戏设定
> 2. 地形多样，**包含并扩张**之前的所有地图元素
> 3. **衔接可解释**——每一处交界都要有因果，不许硬拼

## 0. 这个世界的雕刻者

地球的地理逻辑链是 `高差 → 水 → 侵蚀 → 资源 → 村落 → 城镇`，驱动力是重力和水，**水破坏秩序**。

K-11 不套用这条。它有自己的雕刻者：**同化**。

> **地球的雕刻者破坏秩序；K-11 的雕刻者制造秩序。**

同化不销毁、只并入（世界观暗层二）。所以**地表被同化得越深，越"像是被设计过的"**：层理变规整 → 山脊开始对齐 → 形态开始重复 → 趋近几何与结晶。

强度场是**基准场残余**：原住文明的基准装置关停后留下的余场。场强高的地方同化被挡住，地表保持**生土**（破碎、混乱、天然）；场强衰减的地方，秩序逐级长出来。

对应链：

| 环 | 地球 | K-11 |
|---|---|---|
| 基底 | 抬升 + 岩性 | **真实 DEM 照抄**（与威尼斯 OSM、重庆 DEM 同一条成功路线） |
| 雕刻 | 水力侵蚀 → 混乱 | **同化 → 秩序化** |
| 强度场 | 降水 | **基准场残余** |
| 资源 | 矿脉、泉眼 | **遗构分布 = 同化深度**，越深越值钱越危险 |
| 聚居 | 泉边高地 | **原住文明住在基准场护住的生土口袋里** |
| 边界 | 分水岭 | **封停环**——九十七枚封停件那道线 |

**这条链免费解释掉的东西**：视觉梯度＝难度梯度（不需要 UI）；远处遗构为什么更值钱；三档同化体为什么分三档；失谐为什么是"读数与实感对不上"（你站在秩序化地表上，仪器说天然，脚下感觉是被造的）。

## 1. 分区（同化度由内向外递增，但被节理走向扭曲，不是同心圆）

### P0 · 投射坐标　`r 0–35m`
**性质**：**不是人造地貌**。勘察局按标准评分**选中了一处本来就相对平整的坐标**投射进来——地形是天然的，人为的只有"选择"这个动作本身。

- 承载：基准核心 CS-07、存放半径 700、穹顶＋天窗、信标光柱、玩家出生点、掩体环
- 选址标准（＝评分函数，选址由它算，不由人摆）：**相对平整**／排水良好不积水／高出周边可控场／临近水源但不涉水
- 形态：**相对平整，不是死平**。参考实测——`evolve.js` 选出的候选点在 30m 范围内有 237cm 起伏、高出周边 7.9m，这就是"相对平整"该有的样子
- **衔接**：P0 与 P1 之间**没有硬边**，是同化度的连续过渡。视觉分界靠的是基准场护住的生土 vs 外圈开始出现的秩序，不是一道墙
- **掩体的来源随之改变**：既然没有工程挖填，掩体就不是挡土墙，而是**勘察局部署的可修复屏障**（这正好解释了"打坏后花配额修"），混编天然岩台与露头
- **解释了**：核心周边为什么平——因为平才被选中，不是因为被推平

### P1 · 生土带　`r 35–90m`
**性质**：基准核心投射的基准场挡住同化，这一圈保持未被秩序化。

- 自然元素：破碎岩、**天然（不规整）岩层层理**、**山坡**、**盆地**（核心坐在盆底）、冲沟、**干涸河谷**
- 承载：**6 条丧尸直线道**、废墟 RB×51、弹跳台×16（改造成天然岩台跳点）、坡道 RA
- **衔接（关键）**：**6 条丧尸道就是 6 条干涸河谷**。它们笔直、贯通、通向核心，是因为水曾经这样流；同化体沿它们推进，是因为那是唯一的低阻通道。这一条同时解释了丧尸道的地质成因和 AI 的直线约束。
- **衔接**：外缘＝基准场衰减到临界值那条线，秩序从这里开始出现

### P2 · 初阶同化带 · 原住城区　`r 90–180m`
**性质**：同化刚起步，只把街巷"规整化"，没有吞掉建筑。

- 承载：**威尼斯 201 栋街区全部在这里**、宝物点池×20、武器点池×14、路灯×69、火光×30
- 自然元素：**岩溶泉出露点**（供水，城才长得起来）、**灰壤洼地**（红壤洼地的黑白灰版本）、**地表植被＝灰苔**
- **衔接（关键）**：威尼斯那种"既有机又有秩序"的迷宫质感，正是初阶同化的视觉定义——**不需要改一栋楼，现有街区直接就是这一带的定义性景观**
- **对账**：记忆里宝物点距核心 100m+、武器点 94m+，**正好落在 P2 范围内**，无需搬动
- **衔接**：城的边界＝泉水供给范围 ∩ 基准场边缘

### P3 · 中阶同化带 · 峰丛山地　`r 180–260m`　**（全图落差的主要来源）**
**性质**：秩序显性化，而且是**山地**。峰丛开始等距，洼地开始规则化。

- 自然元素：**峰林**、**峰丛**、**山地**（峰体相对高差 **40–90m**）、**落水洞**、**灰壤洼地**、**干涸河谷**（地表水系的终点）、**悬崖与岩台**（层理差异侵蚀）
- 承载：旧三级台地的"垂直度"在这里被吸收并**放大一个量级**——从 ±4m 变成 40–90m
- **落差依据**：参照已验证的重庆研究（山城巷／南纪门 DEM 实测起伏 **144m**，当时用户认可了垂直度）。本图 495×460m 内做到**全图总落差 120–140m**，与该量级一致
- **复杂度来源**：峰丛之间是**互不连通的洼地群**，绕行成本高、视线被反复切断——这是"较为复杂"的主要贡献者
- **衔接（关键）**：干涸河谷从 P1 流出来，在 P3 钻进**落水洞**——**地表水系在此消失，这就是第一层与第二层的接口**。karst 剖面图上的"雨水下渗路径"就是这一段。

### P4 · 深阶同化带 · 封停环　`r 260m+ / 图缘`
**性质**：近乎几何的结晶态地表。

- 承载：塔碑（Boss 体量在这里定）
- 设定元素：**九十七枚封停件摆成圈＝封停环**，秩序在这条线外戛然而止
- **衔接**：环内是同化已完成的秩序地表，环外是原住文明关停装置后留下的"未完成"地带——这条硬边是全图最强的视觉分界，也是玩家能看懂"这里发生过什么"的唯一现场

### L2 · 第二层 · 地下暗洞系统
**性质**：独立的一层，有自己的地形起伏、自己的层理、自己的秩序梯度。**面积小于地表层**。

> **⚠️ 硬约束（用户 2026-08-10 定）：分层天坑设计必须保留，不得再被简化掉。**
> L2 不是景观，是**必要玩法**：**结局二的关键道具在地下一层**——玩家要打败 CS-07，就必须下到 L2 去拿。
> 这与世界观「契约变更」那条对齐：C7「Boss 打不死」已推翻为可击败，解锁途径是**险区勘探阶段的隐藏关键道具**。
> 因此天坑是**唯一的垂直贯通口**，它的可达性、光照、危险度都是玩法参数，不是美术选择。

- 自然元素：**地下暗洞系统**、**钟乳石**、**石笋**、**石灰岩层理**、**地下水汇聚区**、**岩石溶蚀作用区**、**巨型洞厅＋天窗光柱**、**洞口框景**
- 入口（＝第一二层的通道，洞只是门）：**天坑**（塌陷）、**落水洞**（P3 的水口）、天然断口
- **成因链**：P3 的水从落水洞下渗 → 沿节理溶蚀出管道 → 管道随上游汇水量长大成洞厅 → 顶板失效 → **塌成天坑**。天坑位置不是摆的，是这条链算出来的。
- **地下也有同化梯度**：越深越秩序化。三格遗构（双生钥·启／封、基准核心·初代残件）在最深处
- **尺度依据**（实测参照，按地图 1/3 缩放）：Hang Son Doong 主廊 200×150m、塌陷天窗口径 110／163m；小寨天坑 626m 宽 × 666m 深（深:径≈1:1）；Sarawak Chamber 600×435×115m
- **衔接**：天坑口是两层唯一的视觉贯通。光柱打下来那一眼，就是叙事的高点。

## 2. 多样性怎么保证（两重）

1. **真实 DEM 多源拼接**——不同真实地点＝天生不同的地貌，照抄而非生成（与威尼斯 OSM、重庆 DEM 同一条已验证路线）
2. **同化梯度**——同一块地貌在 A=0 / 0.3 / 0.6 / 1.0 下呈现四种完全不同的面貌

两者相乘，五个地表省份 + 一个地下层，彼此不重样。

## 3. 地表材质（全灰阶，按同化度分层）

无叶绿素，**层与层只靠明度和颗粒区分，绝不靠色相**：

| 层 | 明度 | 规则 |
|---|---|---|
| 盐霜结壳 | .78 | 平坦 + 高处 |
| **灰苔** | .52 | 平坦 + 中低，避风 |
| 灰壤 | .40 | 缓坡 |
| 砾石 | .29 | 坡 25–41° |
| 裸岩 | .19 | 坡 >41°、崖面、坑壁 |
| 湿暗层 | .09 | 洞底、最低洼 |

阈值加噪声抖动，过渡线不得成为等高线。同化度越高，**层界越规整**——材质本身也参与叙事。

## 4b. 各个维度的可解释性（逐维核对）

| 维度 | 由什么决定 | 一句话解释 |
|---|---|---|
| **平面分布** | 基准场残余强度 + 节理走向 | 同化度由核心向外递增，被节理扭曲，所以不是同心圆 |
| **垂直分层** | 溶蚀管道发育深度 | 地表水在 P3 下渗，在深部溶蚀出第二层 |
| **高低落差** | 溶余作用：可溶岩被带走，残丘留下 | 峰丛是"没被溶掉的部分"，洼地是"被溶掉的部分" |
| **地表材质** | 坡度 + 高程 + 同化度 | 同化度越高层界越规整——材质本身参与叙事 |
| **植被（灰苔）** | 泉水供给范围 | 只在 P2 泉眼可达处成片，别处零星 |
| **水** | 地表 → 落水洞 → 地下 | 地表几乎无水（都漏走了），这解释了"干涸河谷" |
| **资源（遗构）** | 同化深度 | 越深保存越完整、越值钱、越危险；三格遗构在 L2 最深处 |
| **聚居（城区）** | 基准场护住的生土口袋 + 泉眼 | 原住文明住在同化进不来的地方，靠泉水活着 |
| **敌人分档** | 地表同化度三档 | 表层／渐进／渗透同化体，与地表三档一一对应 |
| **光照** | 天坑与落水洞的开口 | 地下唯一的自然光来自塌陷口，光柱即导航 |
| **玩法难度** | 视觉梯度＝难度梯度 | 越"秩序化"的地表越危险，不需要 UI 提示 |
| **失谐** | 站在秩序化地表上 | 仪器读数说天然，脚下实感是被造的——本作的语言标记 |
