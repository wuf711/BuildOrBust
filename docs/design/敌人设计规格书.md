# 第一部 · 设计契约

以下七条是不可动摇的红线。任何后续改动如与之冲突，改动作废。

| # | 契约 | 约束的是什么 |
|---|---|---|
| C1 | 敌人是**被同化的人**，不是野生怪物。外观必须留人形痕迹或装备残骸 | 美术 |
| C2 | 普通同化体的 AI 目标是**基准核心**，玩家只是拦路的次级威胁 | AI |
| C3 | 同化程度**由潮次决定**，同潮次内档位单一 | 编排 |
| C4 | 每种敌人有**一个可复述的动词**，玩家事后能说"那个拥的" | 设计 |
| C5 | 至少两种敌人的行为**由玩家自己的失谐读数触发** | 系统 |
| C6 | **任何敌人禁止在玩家相机视锥内生成**，必须从视野盲区或掩体后走出 | 刷怪 |
| C7 | **玩家永远打不死 CS-07**，胜利条件是撑到回收通道 | 叙事 |

# 第二部 · 视觉基底

## 2.1 材质双层

| 层 | 内容 | 参数 |
|---|---|---|
| Layer 1 | 原住底色（青铜／黑铁铸件）或勘察局工装（哑光织物＋战术尼龙） | 金属度 0.8，粗糙度 0.35 |
| Layer 2 | 同化晶体（灰白，长得像盐花） | 粗糙度 0.15，弱次表面散射，0.5 Hz 顶点微颤 |

两层用顶点色遮罩混合。**同一个材质球改遮罩就能出全部变种。**

## 2.2 三派视觉母题

| 派系 | 晶体生长方式 | 音效母题 | 占比 |
|---|---|---|---|
| **接受派**（停锚者） | 完美对称，如王冠／圣袍／花冠。躯壳被温柔包裹，动作舒缓狂热 | 低吟诵、齐步、绵长嗡音 | ~55% |
| **抵抗派**（持锚者） | 从内部粗暴刺穿护甲，不对称、撕裂 | 金属撕裂、粗重回响、短促呼气 | ~30% |
| **外来者**（勘察局先驱） | 寄生在现代战术装具上 | 战术动作肌肉记忆：短促呼吸、装具扣响、通讯口令 | ~15% |

## 2.3 出场顺序（信息设计）

第 1–2 潮几乎全是接受派 → 第 3 潮抵抗派进场 → 第 5 潮外来者零星出现。

让玩家先建立"这是本地怪"的错觉，再意识到"前面还有人来过"，最后自己拼出"这是入侵"。

## 2.4 骨架与预算

| 骨架 | 用于 | 备注 |
|---|---|---|
| `SK_Native_Light` | 原住轻型人形 | 可从现有丧尸骨架改 |
| `SK_Native_Heavy` | 原住重型宽肩 | 同上，加宽肩宽 |
| `SK_Explorer` | 外来者 | **与玩家角色同源**，可复用玩家移动动画 |

面数：小怪 3–6 k tris，精英 8–15 k tris，Boss ≤ 30 k tris。
**弱点部位必须几何凸出**，让玩家不看血条也知道打哪。

# 第三部 · AI Director（核心系统）

固定权重匀速滴漏会让战斗变成传送带。改用**预算积分制**。

## 3.1 预算模型

每潮次分配一个总预算，敌人按 cost 消费预算。方程保持纯粹，不引入时间常数。

```
潮次总预算    B(n) = B₀ · (1 + k·n)          n = 潮次序号，k = 增长系数
瞬时投放速率  R(t) = B_remain · I(t) / T_remain
```

`I(t)` 是**强度包络**，用分段常数实现波峰波谷，不用连续函数：

| 潮次进度 | I 值 | 体感 |
|---|---|---|
| 0 – 20% | 0.6 | 试探期，玩家整理站位 |
| 20 – 50% | 1.0 | 正常压力 |
| 50 – 70% | **0.3** | **喘息期**，玩家换弹、拉人、重新分工 |
| 70 – 100% | 1.6 | 高潮，预算集中倾泻 |

喘息期是这套系统的价值所在。没有它，玩家从头到尾被匀速推着走，疲劳而无记忆点。

## 3.2 压力阀（两条规则，不做情绪状态机）

```
if (最低玩家 HP < 30%)              I ×= 0.5
if (全员 HP > 80% 且 场上清空)      I ×= 1.3
```

只有这两条。刻意不做 L4D 那种复杂的情绪状态机——两条规则已经覆盖 90% 的体感需求，多余的状态只会让节奏难以调试。

## 3.3 配比控制

常规倾泻靶权重 7、战术交互体权重 3，作为**投放概率**而非硬配额。按潮次调整：

| 潮次 | 常规 : 交互 | 意图 |
|---|---|---|
| 1 – 3 | 8 : 2 | 放水期，建立信心 |
| 4 – 6 | 7 : 3 | 标准配比 |
| 7 – 10 | 6 : 4 | 加压期 |

**硬约束**：任一时刻场上**最多两种**战术交互体共存。超过就把新交互体降级为常规靶。这条不可协商，否则玩家反应带宽被打满。

## 3.4 生成位置（契约 C6）

用 UE5 EQS 查询，筛选条件按优先级：

1. 不在任何玩家的相机视锥内（`Dot(ToPlayer, PlayerForward) < cos(FOV/2 + 10°)`）
2. 有掩体遮挡或在拐角后
3. 距最近玩家 ≥ 15 m，≤ 45 m
4. 导航网格可达基准核心

全部不满足时**延迟生成**，不降低标准。宁可空 2 秒，也不能让玩家看见凭空出现。

# 第六部 · CS-07 模因终端（第 10 潮）

## 6.1 定位（契约 C7）

抵抗派倾尽全族之力建造的终极基准发生器，如今沦为同化物质的最高主板。**玩家打不死它。**

- Boss HP 是**抗性槽**，玩家 DPS 只在加速撤离倒计时
- 真正的胜利条件：**撑够最后 90 秒回收倒计时**
- 全程不打：倒计时按 90 s 走，能过关但灰头土脸
- 全程打对：抗性三段衰减完，倒计时提前 45 s，结算多一个"高效撤离"评价
- **无论哪种打法，撤离那一刻 Boss 仍在场，仍在活动**

## 6.2 三阶段

### 阶段一 · 权限剥夺（抗性 100 → 66%）

Boss 倾泻低速红色弹幕（可躲）。场地边缘生成 3 处闪红光的**无效遗构**。玩家在弹幕缝隙中搬运它们到 Boss 侧面的残存接收端口"录入"，每录入一件烧毁 15% 抗性。

*设计意图*：让玩家做和平时一样的事（搬运＋录入），但在弹幕下。他们会突然意识到——平时录入的动作，其实是在给这个东西 debug。

### 阶段二 · 对称性破缺（66 → 33%）

Boss 升起绝对防御折射盾（普通伤害 100% 反弹）。场内四处升起能量柱。

- **玩家 A** 只看得见弱点柱的**几何外壳形状**（三角／螺旋／六边／方）
- **玩家 B** 只看得见能量柱上的**晶体纹路**

两人必须在尸潮干扰下语音对齐。打错柱子会引出一波额外朝圣晶簇。
**单人模式**：两种信息合并显示，但要求玩家在弹幕下自行配对。

### 阶段三 · 静默走廊（33 → 0%，最后 30 秒）

详见 6.4。

## 6.3 抗性衰减的物理表现

光靠 UI 数字跳动，玩家倾泻成吨弹药只换来一行数字，反馈会非常疲软。三个节点各配一次可见的结构破坏：

| 节点 | 表现 |
|---|---|
| 100 → 66% | 塔碑**中段**晶体大面积崩裂剥落，碎块砸地弹跳（物理），露出青铜刻纹 |
| 66 → 33% | **上段**晶体崩落，露出机械结构，**接缝处开始喷火花**并持续到战斗结束 |
| 33 → 0% | **基座**晶体崩尽，塔碑发出低频结构呻吟并**下沉 30 cm**，火花变持续电弧 |

**破坏是真的，击败是假的。** 这个反差本身就是这场 Boss 战想讲的东西。

## 6.4 最后 30 秒的抗压设计

**核心矛盾**：绝命狂奔的压迫感，与"死了要重开十潮"的惩罚天然打架。
**解法**：压力全放感官层，致命性全部收回。

### 移速：把"跑"从操作考验改成资源决策

| 项 | 数值 | 意图 |
|---|---|---|
| 基础移速 | **+25%** | 叙事上是"武器锁死＝卸掉负重"，玩家一进阶段三就觉得身体变轻 |
| 冲刺 | **本阶段取消体力消耗** | 绝命狂奔就该能一直冲 |
| 举灯移动 | **−15%** | 形成"举灯慢而安全／收灯快而掉血"的**每秒决策** |

玩家不是在开局规划路线，而是每一秒重新决定要不要举灯。认知负载只有一个二元选择，节奏感却极强。

### 受击：环境只施压，不杀人

| 来源 | 数值 |
|---|---|
| 失谐力场（裸奔） | −2% 最大 HP／秒 |
| 失谐力场（举灯范围内） | −1%／秒 |
| **血量下限保护**（隐藏，不告知玩家） | 力场压到 **15% HP 即停止扣血** |
| 朝圣者接触（**唯一致命源**） | −20% HP ＋ 1.5 s 无敌帧 |

按 30 秒算：全程裸奔掉 60% HP，全程举灯掉 30%。**玩家哪怕从头裸奔到尾也不会死于环境。** 力场只把血线压进红区，让屏幕边缘一直在闪。朝圣者移动极慢、路线固定，老远就能看见，低血量下要连撞三次才倒。**得死得很努力才行。**

### 谐振灯一物两用

| 用法 | 效果 |
|---|---|
| 照自己 | 力场伤害减半 |
| 照朝圣者 | 被照到的停 **3 秒**，阻止它合并 |

一件道具两个互斥用途，不需要额外教学。玩家每秒的取舍变成：**这盏灯是保命，还是拖住那个正在合并的？**

另有两条可选路径：投掷高爆装药清一片；或什么都不做纯逃。三条路都能通关，结算评价不同。

### 容错三层

1. 谐振灯本阶段有 **3 次点亮机会**，每次持续 8 s。用光了纯裸奔——按上面数值也死不了
2. **双人：一人倒地另一人继续，倒计时照走**。回收降下时倒地玩家自动被拖上通道
3. **单人：力场伤害减半**（−1%／秒，举灯 −0.5%）

### 压迫感来源

- **视觉**：全屏黑暗，谐振灯只照亮 4 m，朝圣者从黑暗里逐个浮现
- **听觉**：唯一的声音是朝圣合唱，越靠近 Boss 越响。**玩家自己的脚步声被模因干扰压掉**
- **心理**：抗性条在**回涨**，玩家眼睁睁看着自己在输，但知道只要活着就赢。**"明知在输，只要撑住就算赢"** 才是这 30 秒真正的张力
- **倒计时始终可见**，最后 10 s 变红加心跳节拍。恐慌必须是可控的恐慌

## 6.5 音效

Boss 全程沉默，只在阶段切换时说一句结构化短句，发音接近勘察局无线电：

| 时机 | 台词 |

# 第七部 · 处决者（触发型）

玩家失谐触顶（100）即刻降临。

- **外观**：细长三米镜面反射体，玩家能在它身上看到自己扭曲的倒影。这是唯一暗示"它可能是 K-11 生成的标准玩家版本，用来把偏差过大的原件纠正回去"的视觉线索
- **机制**：沿玩家方向直线接近，穿墙，不穿核心。伤害极高
- **脱离手段**：失谐压回 70 以下（追一段后消失）／躲进基准场（进不去）
- **击杀条件**：**引它进入 1 盏便携谐振灯范围，手动打爆那盏灯**，过载谐振场将其放逐

**为什么是 1 盏不是 3 盏**：失谐触顶、无敌怪直冲脸的瞬间，玩家本能是跑。要求他一边狂奔一边在残骸里规划穿过三个光圈的路线，是在恐慌状态下考验空间规划，联机实战几乎做不到。1 盏之后决策变成**当场就能做的取舍**：要不要为甩掉它烧掉一件保命道具。

- **音效**：脚步是玻璃碎裂声，越近越清晰

# 第八部 · 失谐钩子总表

| 档 | 阈值 | 触发的敌人行为 |
|---|---|---|
| 同步 | 0–40 | 无 |
| **偏移** | ≥40 | 失步者走火频率 ×2；传道者认知滤镜延长至 5 s；拥抱者狂化阈值 30% → 50%；滤网背负者爆破半径 4 → 6 m |
| **失谐** | ≥70 | 跃迁斥候扑距 6 → 9 m；拾荒残躯"修补"变"吸收"（远程也能吃遗构） |
| **崩裂** | =100 | 处决者出发 |
| **≥80（特例）** | — | **侵蚀温床孢子囊张开**（正向出口） |

**双向策略层**：
- **压失谐流**：躲温床、防致盲，代价是打不出温床的正向出口
- **拉失谐流**：主动做温床诱饵、承担扰乱，代价是随时招来处决者
- **双人**：失谐各人各算，天然把两条路线绑到两个玩家身上——一个诱饵一个输出

# 第九部 · 交互心流铁律

FPS 肉鸽的爽快感建立在不被打断的心流上。以下三条约束局内交互：

| # | 铁律 |
|---|---|
| F1 | **浅位单箱或深位直取**。路过配额或遗构，按下交互键立刻进账或跟随 |
| F2 | **局内禁止任何需要停步的背包整理**。不做双箱合并、不做格子拖拽、不做丢弃确认 |
| F3 | 容量已满时拾取，**自动替换分值最低的一件**并飘一行提示，不弹窗、不暂停 |

高压防守阶段一旦被 UI 整理打断，绝境求生的沉浸感就毁了。背包详情、遗构 flavor 这类阅读性内容**只在补给时段可看**。

# 第十部 · 技术实施

## 10.1 数据表结构

`DT_BoBEnemy`，每行一个型号：

| 字段 | 类型 | 说明 |
|---|---|---|
| `RowName` | Name | 型号 ID |
| `DisplayName` | Text | 显示名 |
| `Faction` | Enum | 接受／抵抗／外来 |
| `Tier` | Enum | 游离／共生／升华 |
| `Role` | Enum | 常规／交互／精英 |
| `SpawnCost` | int | **Director 预算消耗** |
| `HP` / `MoveSpeed` / `Damage` | float | 基础属性 |
| `FrontalDR` | float | 正面减伤（重甲类） |
| `WeakpointBone` | Name | 弱点骨骼 |
| `GazeHookBand` | Enum | 触发档位 |
| `GazeHookParam` | float | 触发后的参数变化 |
| `SkeletonAsset` / `AttachmentSet` | SoftPtr | 骨架与配件组 |
| `WarnSFX` / `LoopSFX` / `DeathSFX` | SoftPtr | 三段音效 |
| **`BuildCheckNote`** | **String** | **策划备注：它在质检什么** |

`BuildCheckNote` 是给设计侧看的，不进游戏。它反过来指导投送端商品设计——每件商品都应该在补某项质检的短板。

## 10.2 类结构

```
AShooterNPC（现有基类，扩展）
 ├─ ANPC_Pilgrim        朝圣晶簇（含 2 变种，走数据表）
 ├─ ANPC_Embracer       拥抱者
 ├─ ANPC_Sower          侵蚀温床
 ├─ ANPC_Martyr         殉道重甲
 ├─ ANPC_Scavenger      拾荒残躯
 ├─ ANPC_FilterBearer   滤网背负者
 ├─ ANPC_Runner         跃迁斥候
 ├─ ANPC_Misstep        失步者
 ├─ ANPC_Caller         传道者
 └─ ANPC_Mimic          完美镜像

ABoBAIDirector（新）      预算积分、强度包络、EQS 生成点
ABoss_CS07（新）          三阶段状态机
AExecutioner（新）        处决者
```

变种不建新类，全部走数据表 + Socket/Hide Bone。

## 10.3 尸体处理

倒下 3 秒后 Ragdoll → StaticMesh，碰撞简化为单个 Capsule。视觉上晶体从躯壳内漫出把尸体裹成灰白结晶体。

**切换帧必须用粒子掩盖**：生成一次晶体粉末爆开（Niagara，灰白细颗粒向上飘散 0.6 s ＋ 地面一圈薄扬尘），把姿态跳变藏进粒子里。不做的话玩家每次杀怪都会看到一次僵硬定格。

保留"用尸体堆掩体"的战术奖励（拥抱者冲锋撞尸墙的解法就靠它），同时把复杂物理演算降维成静态障碍。

## 10.4 完美镜像的网络同步

不做位置回放（原方案"沿玩家 3 秒前路径走"服务器成本极高且易拉扯）。改为：

- 服务器只持有一个「锁定宿主 PlayerId」
- 客户端渲染时对宿主强制替换头部材质为空白合金板，其他客户端正常渲染
- 伤害计算查这个 PlayerId 决定是否归零

同步开销约等于零。

## 10.5 实施顺序

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **1** | `DT_BoBEnemy` 表结构 + `AShooterNPC` 读表改造 | 现有丧尸能从表里读属性 |
| **2** | `ABoBAIDirector` 预算积分 + 强度包络 + EQS 生成点 | **用现有丧尸就能验证节奏曲线**，能感受到喘息期 |
| **3** | 三套骨架 + 前两组配件（花冠／装甲） | 前 6 潮 70% 刷怪量有正确外观 |
| **4** | 常规靶四种 AI + 交互体六种机制 | 21 型号全部可玩 |
| **5** | `ABoss_CS07` 三阶段状态机 | 第 10 潮完整 |
| **6** | `AExecutioner` + 失谐钩子接线 | 失谐经济闭环 |

**阶段 2 是关键节点**：Director 做完当天就能用现有资产验证"这游戏打起来爽不爽"，不必等美术。刷怪节奏是手感问题，越早试错越省。Boss 是演出问题，晚两周不影响主循环验证。
