# K-11 结局分支与系统逻辑总纲

## 一、结局分支定义与判定逻辑

### 【结局一：局部撤离】（默认存活线）

- **触发条件**：存活至第 10 潮次倒计时归零，且基准核心耐久度 > 0。
- **执行流程**：撤离通道开启（直升机从穹顶降下） → 玩家进入触发区 → 结束战局并进入结算界面（依据击杀与回收遗构计分）。
- **系统标记**：执行 `RunEnding = 1`。
- **剧情锚点**：达成基础存活与勘察目标，未对 K-11 生态产生实质影响。

### 【结局二：核心摧毁】（破坏线 / 已实装）

- **触发条件**：在最终战中，将 CS-07 的抗性槽完全清零。
- **前置解锁链（资源与难度博弈）**：
  1. **门槛判定**：玩家个体失谐值须 ≥ 50，方可解锁"封停件"的交互权限。
  2. **经济消耗**：必须消耗局内【配额】（与军备抢占资源池），在 97 枚封停件中成功唤醒 9 枚。
  3. **全局惩罚**：每成功唤醒 1 枚，全场失谐值增长速率永久提升 +0.18。
- **全局视觉进度**：西南天坑的光束亮度随唤醒进度逐级提升（作为去 UI 化的全局进度指示器，两名玩家抬头可见）。
- **系统标记**：执行 `RunEnding = 2`。

### 【结局三：协议覆写】（隐藏解密线 / 待实装）

- **触发条件**：获取"第九十八枚封停件"，并在最终面临 CS-07 时选择第三交互项"插入封停阵列"。
- **前置解锁链（极限高危解密）**：
  1. **碎片收集**：在地图特定坐标（详见第二节）集齐 3 份前代外来者遗留物，用以补全空白封停件的刻录逻辑。单件拾取无 UI 任务提示。
  2. **进度确认**：集齐 3 份线索后，天坑光束触发"变色"材质切换，并弹出现场文本。
  3. **高危交互（处决者判定）**：玩家必须主动将失谐值拉满至 100 触发【处决者】降临。**仅在处决者存活且处于追击状态时**，玩家方可对空白封停件执行刻录交互。
- **系统标记**：执行 `RunEnding = 3`。

## 三、底层交互机制开发备忘

1. **反直觉任务引导**：本作舍弃任务清单 UI。小地图仅暴露已探索区域的资源标点（战利品 56m、野生红点 32m、勘探物 65m）。进度反馈全部挂载于环境美术（如天坑光柱的亮度/色相变化）。
2. **高危状态锁**：系统需新增失谐值的布尔值锁。部分物品或交互权限强绑定 `if (Player->GazeBand >= 50/60/100)`。这是本作核心的"容错率换进度"机制。
3. **信息降噪设计**：场景中故意放置可交互但无效的"世界观碎片"。旨在防止玩家利用"按 F 穷举法"推图，强迫玩家阅读环境信息。
